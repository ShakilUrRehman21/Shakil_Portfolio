## 🏃 Getting Started Locally

### 1. Prerequisites
- Node.js (v18.17.0 or later)
- npm or yarn

### 2. Clone the Repository
```bash
git clone https://github.com/ShakilUrRehman21/Shakil_Portfolio.git
cd Shakil_Portfolio
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Production Build
```bash
npm run build
npm run start
```
